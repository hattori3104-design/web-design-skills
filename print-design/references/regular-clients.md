# 反復クライアントの定番仕様

毎年・毎回繰り返す紙もの案件の「お約束」を蓄積するファイル。
案件が終わるたびに、確定した仕様・学びを追記する（次回の自分への引き継ぎ）。
「推定」「要確認」と付いた項目は、次の案件で確定したら書き換えること。

---

## Asterism（クリスマスコンサート「ルーマニアのクリスマス」）

**初版作成: 2026-07-05（2025年版データからの抽出。推定含む）**

### 案件の性質
- 毎年12月開催・複数会場（過去実績: 八王子・世田谷・高津 ※会場名の漢字は要確認、ファイル名は takatsu）・複数日程
- **毎年、昨年版データをベースに更新する**運用（案件フォルダに `03_昨年データ/` あり）
- 会場別バージョン＋全会場版＋英語版を作り分ける（2025年版は計7種）

### データ仕様（2025年版PDFから確認）
| 項目 | 内容 | 状態 |
|---|---|---|
| 仕上がりサイズ | 235×322mm・2ページ（A4二つ折りパンフレットと推定。**標準サイズと一致しないため要確認**） | 推定 |
| カラーモード | CMYK | 確認済 |
| 制作データ | Illustrator（.ai）＋PDF書き出し | 確認済 |
| 用紙・印刷会社・部数 | 記録なし | **要確認** |

### ファイル命名ルール（確認済）
- `Christmasconcert_[年]_[会場]_[版].pdf`
- 会場: `all`（全会場）/ `hachioji` / `setagaya` / `takatsu`、英語版は `english`
- 版: `_01`＝本番版、`_02`＝校正版（推定）

### 毎回の必須掲載要素（2025年版から抽出）
1. タイトル・開催日時（複数会場×複数日程）・会場名・開場/開演時刻
2. 出演者情報（指揮者・主要奏者のプロフィール写真、合唱団の団体写真）
3. チケット情報：料金（2025年は5,000円均一）・購入方法複数（チケットぴあ／Confetti／窓口）・Pコード・電話番号と受付時間・QRコード（購入経路別）
4. **18歳以下学生無料招待**の企画枠（条件表記：保護者同伴・対象外日程あり等。年により条件が変わるので毎回確認）
5. プログラム紹介（朗読×音楽セクション、合唱セクション、YouTube QR）
6. 3会場の地図＋駅からのアクセス
7. フッター：制作・協力団体、公式サイト（romanian-christmas.com）、連絡先（music@asterism.tokyo）、後援ロゴ（東京都関連など）

### デザインの連続性
- クリスマスカラー（赤・ゴールド）＋ルーマニア装飾・雪の結晶モチーフが昨年までの基調
- 日本語版と英語版の2言語展開
